Before producing anything, pin down the actual goal: **$ARGUMENTS**

Do not start the work yet. First return:

1. **Goal in one sentence** — the concrete outcome, stated so it's obvious when it's been hit.
2. **Done looks like** — 3–5 specific, checkable criteria. Not "high quality." Something you could tick off.
3. **Out of scope** — what this explicitly is *not*, so the work doesn't sprawl.
4. **Unknowns** — anything you'd have to assume to proceed. State the assumption you'd make and how much it changes the output if wrong.

Then stop and ask: *proceed on this, or adjust?*

Keep the whole thing under 200 words. If the goal is already unambiguous, say so in one line and move straight to the work rather than padding this out.
